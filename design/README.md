# 🎨 Design Mockups & Wireframes (`design/`)

This directory contains standalone HTML/CSS wireframes, design exports, and interface references created during the initial visual design phase.

---

## 📂 Subdirectories

* `admin_dashboard_munch_tokri/` — Initial HTML prototype of the admin panel.
* `admin_inventory_control_munch_tokri/` — Inventory management UI reference.
* `admin_orders_management_munch_tokri/` — Orders control center design mockup.
* `homepage_hurigalu_angadi/` — Initial visual prototype of the storefront home.
* `build_your_own_mixture_html/` — Interactive mixture builder prototype.
* `checkout_html/` — Checkout layout and flow reference.
* `user_dashboard_munch_tokri/` — Customer profile and orders dashboard reference.

> **Note**: These files are historical design references. The actual production UI lives entirely inside `src/app/` and `src/components/`.
